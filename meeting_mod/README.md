# Meeting Mod

This folder contains the Meeting Mod — an in-world meeting and voting system implemented with the stable Bedrock scripting API.

How to start
- /function meeting_mod:meeting to request a meeting (tags all players with 'meetingStart')
- Any player can type !meeting in chat to start the meeting

Changes made in this update
- Folder and filenames renamed to meeting_mod and meeting.js
- Actionbar now says "Voting starts in: Ns"
- Titles are displayed with times (10 100 10) so they disappear after ~5 seconds

Notes
- Keep scripting enabled in world settings. The pack requires command execution permission for some operations.
